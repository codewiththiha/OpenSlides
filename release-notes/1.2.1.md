## What's New

- Switched build tooling from npm to bun for faster installs and builds.
- macOS release is now a single universal binary that works on both Apple Silicon and Intel Macs.
- Fixed a visual glitch where closing a project stack on the dashboard would flash briefly.

## Changes

- CI and release workflows now use bun instead of npm.
- macOS downloads are a single universal package instead of separate Apple Silicon and Intel builds.
- Removed unused code paths and centralized internal defaults for cleaner builds.
