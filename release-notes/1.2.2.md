## What's New

- Added PowerShell language support for code slides.
- Separate macOS Apple Silicon and Intel release builds (no more universal-only package).
- Linux releases now ship AppImage alongside `.deb` and `.rpm`.
- Added Nix flake packaging for Linux and macOS.
- Hardened Tauri bundle configuration for production-ready multi-platform builds.

## Changes

- Release matrix builds dedicated `aarch64-apple-darwin` and `x86_64-apple-darwin` artifacts.
- Linux packages include AppImage with a Wayland library fix for newer Mesa stacks.
- Windows continues to ship x64 and ARM64 installers.
- Nix users can install via `nix profile install github:codewiththiha/OpenSlides` after sources are published.
- Content Security Policy and Linux/Windows bundle metadata tightened for release builds.
